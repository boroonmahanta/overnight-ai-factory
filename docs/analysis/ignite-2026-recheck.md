# The Ignite 2026 re-check: what is GA and changes the plan

Date: 23 November 2026 (Session 33, a laptop session in its own worktree). The schedule's checkpoint "Ignite re-check" (`docs/plans/schedule.md`), recorded as ADO story 3024 under Feature 2711. Microsoft Ignite ran from 17 to 20 November 2026. The plan always meant to re-check product names, Copilot Studio evaluation APIs and Git integration after it (plan 1.1, 1.4, risk 27, 15.1).

**Proposals only.** Nothing here edits the plan or `CLAUDE.md`. Boroon decides each change.

## Bottom line

- **No rename.** Power Platform, Power Apps, Power Automate, Dataverse and Copilot Studio keep their names. The naming rule (plan 1.1) needs no change, and no machine-read name moves.
- **The night lane's tools did not change.** Ignite made nothing GA for the Dataverse MCP server, FlowAgent, the App Spec apply, `pac copilot`, the pac solution commands or Copilot Studio evaluation. No pac release writes YAML. Git integration with GitHub is still preview. Spikes 0.4, 0.12 and the XML layout stand as they are.
- **Copilot data residency still covers only the US and the EU.** Risk 4 and the T3 tier stand. Claude still has no Australian path.
- **Nine GA items do touch the plan** (table 1). The most important for us: Copilot Managed Runtime now makes managed developer environments in every tenant and cannot be turned off; Australia East has exactly one current frontier model as a Standard (regional) deployment, GPT-5.6 Sol; the Copilot SDK is GA as "Microsoft Copilot SDK" 2.0 (Lane A); and GitHub's team customizations can now load plugins into day sessions by default.
- Two plan facts were found wrong or settled along the way (section 4): the Power Apps Vibe dates, and Purview, which logs production environments only.

## How it was checked

- **GA only.** An item counts only if a primary source says "generally available", or "now available" with no preview label, and it is available now. Public preview, private preview, Frontier, "coming soon" and future dates do not count. Third-party blogs were used only to find items.
- **Sources read.** The Ignite 2026 Book of News (all of it; it has no Power Platform section), the Power Platform team's Ignite post of 18 November, the Copilot Studio post of 18 November, the GitHub changelog for 1 to 20 November, GitHub Docs (`github/docs`), Microsoft Learn (release notes, region tables, important changes, product pages), Azure updates and blogs, Partner Center announcements, Azure DevOps release notes, and Microsoft's own GitHub repos (`microsoft/copilot-sdk`, `power-platform-skills`, `Dataverse-skills`, NuGet for pac).
- **Who read what.** Four research agents read the sources in parallel, one each for Power Platform ALM, the night tools with Copilot Studio, GitHub, and Azure with licensing. Every row in table 1 was then re-read on its primary page in this session, except where a row says "not re-checked". One agent claim failed that check and is left out: that the Copilot SDK's BYOK takes API keys only. The SDK's own `docs/auth/byok.md` documents Microsoft Entra bearer tokens.
- **Scope.** Ignite week, plus GA items from earlier in 2026 that the plan does not yet reflect and that this check found. GitHub Universe (28 to 29 October) is spike 0.15's job (ADO 2465, 7 December) and was not surveyed. The component register review is a separate item and was not done.

## 4. Facts found along the way (not GA features)

- **The Power Apps Vibe and App Builder dates in plan 1.4 are wrong.** Vibe: editing until 30 November 2026, migrate or download only from 1 to 31 December, "After December 31, 2026: You can no longer access your Vibe apps" ([migrate apps](https://learn.microsoft.com/power-apps/vibe/migrate-apps)). App Builder has the same dates (researcher's reading). The 11 December date in 1.4 belongs to Power Apps Ideas, Copilot formula generation and "Rename controls with Copilot" ([important changes](https://learn.microsoft.com/power-platform/important-changes-coming)). Proposed: split the 1.4 row. Nothing in the plan builds on either, so only the row changes.
- **Purview logs production environments only** (answers a 15.1 question and 5.3's "Confirm whether Purview covers sandboxes"): "Microsoft Purview auditing solutions capture user activity logs only for production environments" ([activity logs](https://learn.microsoft.com/power-platform/admin/activity-logging-auditing/activity-logs-overview)). Lanes and Test are sandboxes, so the alert in 5.3 ("when a lane execution identity appears in any Test, UAT or Prod log") can use Purview for Prod only; for lanes, Test and UAT it must read Dataverse auditing. Proposed: say so in 5.3 and close the 15.1 row.
- **Release plans are retired.** The Release Planner retired by 15 November 2026; roadmap content moved to the "AI at Work roadmap" (Partner Center, September 2026; researcher's reading). Proposed: future re-checks read that roadmap, not release plans (1.1).
- **"Personal developer environments" are now "personal environments"** on Learn (17 November). Prose only.
- **GitHub Copilot retires some models on 14 December 2026** (Claude Haiku 4.5, Gemini 4 Argon and others). Claude Sonnet 5.5 and Opus 5.5, the plan's pins, are not on the list.
- **Latest versions seen:** pac 2.16.1 (20 November); Copilot CLI 1.0.114 (18 November); `@microsoft/dataverse` 1.0.95 (20 November, still preview). For A1 and 2509.
- **AUD cloud prices fall 4% from 1 January 2027** (Partner Center, 11 November; researcher's reading). For the AUD price question in 15.1 and `dim_price` (10.3).
