# Coding standards

This file holds the practice standards this project follows.

- **Who reads it.** The reviewer's standards pass reads it on every pull request and names each breach. The build agent never edits it.
- **Two kinds of standard.** Each standard is marked "rule" or "judgement".
  - **Rule:** a trusted gate lint checks it. A breach can raise the Merge Danger floor.
  - **Judgement:** the reviewer's standards pass checks it. The reviewer may raise the Merge Danger score, with a written reason, never lower it.
- **How it changes.** This file is a protected path. It changes only by a reviewed daytime pull request.
- **Where it sits.** Outside `AGENTS.md`, which points to it and does not copy it.
